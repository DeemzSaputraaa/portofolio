# Kata.ai Clone with Astro.js

This project is a clone of the Kata.ai website built using Astro.js. It aims to replicate the layout, design, and animations of the original site while providing a clean and efficient codebase.

## Project Structure

```
kataai-clone-astro
├── public
│   └── favicon.svg
├── src
│   ├── components
│   │   ├── Header.astro
│   │   ├── Footer.astro
│   │   ├── HeroSection.astro
│   │   ├── FeaturesSection.astro
│   │   ├── AnimationSection.astro
│   │   └── Layout.astro
│   ├── layouts
│   │   └── MainLayout.astro
│   ├── pages
│   │   └── index.astro
│   ├── styles
│   │   ├── global.css
│   │   └── animations.css
│   └── utils
│       └── animations.ts
├── astro.config.mjs
├── package.json
├── tsconfig.json
└── README.md
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/kataai-clone-astro.git
   cd kataai-clone-astro
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```
